# Samples

Every obfuscator sample the tool is tested against, in one place. Third-party
scripts are included only as test data; see each folder's notes for provenance.

| folder | contents |
| --- | --- |
| `luraph-v15/` | Luraph v15 builds for the devirtualizer. `output/` holds the committed reference results (regenerated by `node deob.js samples/luraph-v15/`). |
| `legacy/` | Pre-v15 Luraph: a v14 header sample and a miniature legacy-style loader. |
| `families/` | One real sample per supported obfuscator family (see `families/README.md` for the source of each). |
| `keyforge/` | Synthetic KeyForge delivery chain (loader, delivery scripts, encoded payloads, `--http-map`) built by `test/make_fixtures.js`. No real project or key; the whole chain resolves offline. |

Run the tool against a folder the same way:

```
node deob.js samples/luraph-v15/
node deob.js samples/keyforge/keyforge_loader.lua --key KEY-... \
    --http-map samples/keyforge/http_map.json --no-net -o /tmp/out.lua
```
